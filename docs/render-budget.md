# 高分屏渲染负载与降耗，2026-11-06

用户反馈本地运行时风扇高转。检查时没有残留的 Godot 或 Blender 进程，系统未报告温控或性能警告；这不代表运行时没有较高功耗。保存的自定义画质为全屏、95% 渲染比例、高档云、300 米阴影。旧配置没有倒影项，原实现按开启补齐；帧率项缺失时实际使用 60 FPS。

## 改动

- 新增独立的 3D 分辨率上限：900p / 1080p / 1440p / 原生，默认 1080p。上限与手动比例取较低值，保持宽高比，不放大小窗口；窗口大小改变时重新计算。只调整 3D 缩放，菜单和文字保持输出分辨率。
- 首次启动默认中画质，保留体积雾、死光和辉光，使用半分辨率体积云、180 米阴影并关闭 SSAO 和屏幕空间倒影。已有配置中明确保存的画质继续使用，缺少新上限时补为 1080p。
- 通用帧率默认仍为 60 FPS，后台仍为 15 FPS。此次为反馈设备备份配置后应用中画质、1080p、30 FPS；输入、音量等其他设置逐项核对保留。可在菜单中重新选 60 FPS 或原生上限。
- 不削减怪物数量，不增加逐帧分辨率调节器；缩放只在设置变更及窗口尺寸变化时计算。

## 本机验证

Apple M5 Max、Godot 4.6.2 Metal Forward+；全屏输出 3024 × 1898。固定墓地视角，停止场景脚本运动，保持同一场景与粒子配置。仅在测试内存切换设置，不保存配置。按原设置 / 降耗设置 / 降耗设置 / 原设置执行，分别预热 60 帧、记录 150 帧，各段实际绘制 150 帧，采样时前台有焦点；本轮未并行运行回归测试。

| 指标 | 原设置，两段 | 中画质、1080p、30 FPS，两段 |
|---|---|---|
| 3D 内部分辨率 | 约 2873 × 1803 | 约 1721 × 1080，每帧像素减少约 64% |
| 帧间隔中位数 | 16.674 / 16.651 ms | 33.311 / 33.315 ms |
| 整机 GPU 利用率中位数 | 61% / 60%，6 / 7 个样本 | 24% / 24.5%，13 / 12 个样本 |

利用率来自系统 AGX `PerformanceStatistics` 中的 `Device Utilization %`，约每 350 ms 读取一次；它包含整机其他图形工作，并非游戏独占利用率、耗电瓦数、温度或风扇转速。静态场景短时对比不能代替长时间移动试玩、低配设备或噪声测量。此设备的 Godot GPU 耗时接口返回 0，未将该值当成真实 GPU 耗时。此前并行回归期间的试采样及中断的第二轮未用于上述结果。

临时测量输出为 `/tmp/leviathan-power-probe.json`、`/tmp/leviathan-power-gpu-samples.json`，不作为游戏资产导出。已查看中画质、1080p 的实际墓地画面。
