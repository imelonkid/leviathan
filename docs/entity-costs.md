# 新增实体的成本评估

新增实体在提交前记录数量、三角形、材质/绘制批次、节点、物理/导航、动画更新、声音和新增资源大小；使用实际渲染场景测量，不能用 headless 测试推断 GPU 性能。优先复用授权清楚的现成模型，在 Blender 中统一尺度、材质并减面；特别的怪物和缺少合适素材的部分再自建。

## 乱葬岗乌鸦，2026-11-05

采用 Nodelete 的 [Low Poly Crow – Rigged](https://blendswap.com/blend/7340)，下载包内的 `BLENDSWAP_LICENSE.txt` 明确授权 CC0。原文件和许可保存在 `tools/blender/sources/crow/`，来源与适配说明见 `assets/models/CROWS_CREDITS.md`。`tools/.gdignore` 将源文件排除在 Godot 导入与游戏资源之外。

原基础网格有 1,216 个三角形，包含细分修改器与旧版绑定，没有动画片段。适配时移除修改器与旧绑定，轻量减面，补齐原作 37 个未绑定顶点的分区，按原顶点组拆为身体/头/右翅，镜像复用左翅；补充简化脚爪。栖息、理羽和振翅由共享网格转轴驱动。

### 资源与运行约束

| 项目 | 数值 / 处理方式 |
|---|---|
| 数量 | 4 只，同时最多 2 只惊飞；6 个真实枝端栖息点 |
| 全群几何 | 4,544 三角形；身体 382、头 130、单翅 312，每只 1,136 |
| 绘制 | 3 个 MultiMesh，身体、头、左右翅；共享不透明材质，不投影 |
| 节点 | 群体根节点 + 3 个绘制节点 + 1 个共享 3D 声音节点，共 5 个 |
| 物理 / 导航 | 不新增物理体、骨骼或寻路器；仅起飞时对弧线做世界碰撞扫掠，受阻则停留并延后重试 |
| 动画更新 | 栖息 10 Hz；有鸟飞行时 30 Hz；50 米外/失焦每秒检查一次，不更新姿态、不发声 |
| 声音 | 24～42 秒尝试一次叫声，最大距离 32 米，单声复用；振翅复用已有 CC0 布料拟音 |
| 新增运行资源 | GLB 22,584 字节 + 叫声 OGG 9,910 字节；文件大小不等于运行内存或显存 |
| 死光反应 | 墓地内任一鸟被照到后全群停声、停动作并朝向利维坦，离开后延迟恢复 |

此前占位模型的全群预算为 2,336 三角形、GLB 37,092 字节。换为现成模型后增加 2,208 三角形，绘制批次与节点数量不变，模型文件减少 14,508 字节；没有为复用素材引入运行时骨骼。

### 本机采样

Godot 4.6.2、Metal / Forward+、Apple M5 Max，实际窗口 1280 × 720。固定镜头和场景，停止脚本运动、隐藏 GPU 天气粒子；只在内存里关闭帧率限制与垂直同步，不保存玩家设置。按关闭 / 开启 / 开启 / 关闭顺序采样，每段预热 20 帧、记录 60 帧。CPU 更新另行计时。

| 测量 | 现成模型适配后的结果 |
|---|---|
| 固定视角绘制次数中位数 | 关闭 151、开启 154，增加 3 |
| 固定视角可见图元中位数 | 1,432,184 → 1,433,008；视角内只看到部分鸟，全群预算仍为 4,544 |
| 帧间隔中位数 | 最终采样关闭 8.091 ms、开启 8.063 ms；此前两次差 0.117 / 0.252 ms。波动范围内没有稳定退化，不能据此声称乌鸦提升帧率 |
| 栖息姿态更新 | 中位数 0.008 ms，P95 0.008 ms |
| 飞行动画更新 | P95 0.009 ms |
| 一次起飞路线检查 | 最终采样 0.173 ms，此前最高 0.422 ms；只在惊飞时执行 |

这是此设备、此视角下的增量成本，不能作为低配电脑的帧率保证，也不包含其他实体继续增加后的叠加成本。此前占位版在不同分辨率下的绝对帧耗时不可直接与本次比较。

### 重现与回归

```sh
Godot --headless --audio-driver Dummy --path . --script res://tests/crows.gd
Godot --audio-driver Dummy --path . --script res://tests/crows.gd -- --benchmark
```

有渲染窗口的测试输出 `/tmp/leviathan-crows/performance.json` 和栖息/飞行截图。回归覆盖数量与绘制预算、黑羽顶点色、真实枝端、惊飞与落枝、飞行拒绝穿墙、死光停声、恢复、远处/后台休眠和换图清理。CI 限制全群三角形不超过 5,000、三组单材质网格、不增加骨骼/物理体/阴影；后续模型变化需重测并更新本记录。
